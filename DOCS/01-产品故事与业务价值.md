# 这一帧怎么说：产品故事与业务价值

## 一句话定义

**面向抖音内容学习者的个性化视觉词汇搜索：暂停一帧，找出你不会说的表达，把它变成以后想得起来的帧词卡。**

## 用户问题

用户刷旅行、美食、城市生活或海外 Vlog 时，经常能看懂画面，却说不出画面里的物品、动作和场景表达。

传统搜索要求用户先知道关键词；传统背词 App 又脱离了用户正在看的内容。结果是：好奇心在短视频里被触发，但没有形成学习和记忆。

## 核心洞察

一帧真实画面同时提供了三个传统词卡缺失的记忆线索：

1. **视觉线索**：用户亲眼见过这个对象或动作。
2. **情境线索**：它发生在一段具体视频、人物和氛围中。
3. **兴趣线索**：用户主动暂停，意味着这就是当下真正想理解的内容。

因此，我们不让用户从词表里找单词，而是让单词从用户正在看的世界里出现。

## 产品承诺

> 刷到的世界，都会说英语；暂停这一帧，把你还不会说的那部分带走。

## 完整体验闭环

```text
刷到一段内容
  → 被某一帧吸引，长按/暂停
  → AI 理解画面，识别可学习的物品、动作与场景表达
  → 按用户 CEFR 水平筛选 3–5 个“现在刚好该学”的表达
  → 用户将不会的表达加入帧词库
  → 带画面和例句的帧词卡进入复习队列
  → 用户在之后的碎片时间回忆、确认掌握或安排再见
  → 下次识别跳过已掌握内容，继续推荐下一层表达
```

## 抖音业务价值：为什么会提升重播与留存

这是一个需要在验证中衡量的**业务假设**，不是已经达成的结论。

当用户发现画面里有自己不会的表达时，他会自然地：

- 停留更久，观察被标注的对象或动作；
- 反复回看同一小段视频，确认词和画面的关系；
- 收藏帧词卡，并在词库里回到原视频语境；
- 形成“刷内容时顺手学到一个词”的新使用心智。

由此，视觉搜索不只是一次识别：它让短视频从一次性浏览内容，变成可反复回看的个人学习材料。

### 候选指标

| 指标 | 定义 | 要验证什么 |
| --- | --- | --- |
| 视觉搜索触发率 | 暂停后发起识别的比例 | 入口是否自然 |
| 标注点击率 | 识别结果中被点开的比例 | 词是否真的有学习价值 |
| 入库率 | 点击后加入帧词库的比例 | 识别是否转化为个人资产 |
| 同视频重播率 | 入库前后，同一视频片段的重复播放次数 | 词与视频是否绑得更牢 |
| 复习完成率 | 到期帧词卡被完成的比例 | 碎片化记忆闭环是否成立 |
| 掌握推进率 | 用户从“不认识”到“认识”的比例 | 个性化难度是否合适 |

## 为什么必须是视觉搜索

用户真正的搜索词不是“coffee machine”，而是“画面里咖啡师正在做的这个动作”。他通常无法精确打字描述，也不需要先知道答案。

视频/图片负责提供难以文字化的视觉情境；AI 负责理解对象、动作和关系；用户只需暂停或圈选。这就是视觉输入相对纯文本搜索的明确增益。

## 不做什么

- 不把口语评分、角色扮演或实时语音作为主流程。
- 不默认上传和存储完整视频。
- 不做泛化的“每日背词”产品。
- 不为了识别而识别；每个学习点都必须可以被收藏、复习或明确跳过。
