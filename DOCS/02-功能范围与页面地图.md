# MVP 功能范围与页面地图

## 北极星闭环

`暂停 → 识别 → 收藏 → 复习 → 下次更懂你`

任何不强化这条链路的功能，园会版本都不做。

## MVP 功能

| 功能 | 用户得到什么 | 前端职责 | 后端职责 | 本次必须 |
| --- | --- | --- | --- | --- |
| 视频输入 | 上传本地视频；未来可映射为抖音 Feed 长按暂停 | 上传、播放、暂停、取帧 | 不保存完整视频 | 是 |
| 帧级视觉识别 | 3–5 个有位置、有难度的学习点 | 画面标签、加载、失败重试 | 图像理解、JSON 校验 | 是 |
| 难度筛选 | 同一画面给不同用户不同词 | 等级选择器 | CEFR 提示与筛选 | 是 |
| 词条详情 | 中文、发音、画面例句、搭配 | 词条抽屉 | 详情生成 | 是 |
| 加入帧词库 | 将“不会的词”变成个人资产 | 收藏状态、成功反馈 | 保存词、画面摘要、学习状态 | 是 |
| 帧词库 | 看见来自哪些视频/场景的词 | 列表、场景分组、待复习数 | 读取 saved words | 是 |
| 复习卡 | 看画面线索并确认认识与否 | 认识/再看看两种动作 | 更新掌握度和下次复习时间 | 是 |
| 黑名单 | 不再展示不想学的概念 | “不再出现” | 保存 blocked concepts | 可做 |

## 明确砍掉

- 口语挑战、角色任务、实时语音、语音评分。
- 长连接 WebSocket 音频服务。
- 完整视频云端上传、转码、分享和审核。
- 复杂用户画像、排行榜、社交系统。

## 页面地图

### `/` 商业首页：建立欲望和解释价值

| 区块 | 用户应感受到什么 | 内容 |
| --- | --- | --- |
| Hero | 英语就在正在看的世界里 | 全屏视频/真实画面；漂浮的英语词；标题“每一帧，都有你还没学会的说法” |
| 触发 | 我不需要知道关键词 | “看见却叫不出？暂停就够了。” |
| 识别 | AI 真能看懂画面 | 帧内的词汇标注和 CEFR 标签 |
| 个性化 | 它不是给我塞词表 | 同一画面在 A2/B1/C1 下的不同推荐 |
| 帧词库 | 我学到的会留下来 | 带原画面、例句和掌握状态的词卡 |
| 复习 | 它能让记忆发生 | “认识 / 再看看”的最小复习卡 |
| 抖音场景 | 这不是独立工具 | Feed 长按暂停的模拟入口与“重播这一帧”叙事 |
| CTA | 现在就能试 | “上传视频，搜索这一帧” |

### `/app` 真实产品：完成一次视觉词汇搜索

```text
上传视频 → 暂停当前帧 → 识别标签 → 打开详情 → 加入帧词库
```

### `/library` 词库：证明记忆和留存

```text
待复习数量 → 今日帧词卡 → 认识/再看看 → 掌握状态更新
```

### `/demo` 评委演示：60 秒证明闭环

```text
暂停一帧 → 识别一个动作 → 加入帧词库 → 打开复习卡 → 完成一次回忆
```

## UI 文案替换表

| 旧叙事 | 新叙事 |
| --- | --- |
| 进入这个场景 | 搜索这一帧 |
| 你成为画面里的人 | 这一帧里，有你还不会说的表达 |
| 开始说 | 加入帧词库 |
| 现场纠正 | 看看这一帧里它怎么用 |
| 场景完成度 | 记忆进度 |
| AI 还记得你 | 下一次，它会推荐你还没掌握的表达 |

## 数据与接口最小集

```text
POST /api/analyze        识别当前暂停帧
POST /api/detail         获取词条详情
GET/PUT /api/learning-state 词库、黑名单、掌握度同步
GET/PUT /api/settings    用户语言与难度
```

### 复习调度（足够用于 MVP）

| 用户动作 | 下次出现 |
| --- | --- |
| 第一次收藏 | 1 天后 |
| 点击“认识” | 3 天后，再次认识则 7 天后 |
| 点击“再看看” | 次日 |

## 开发优先级

1. 后端执行 Supabase 迁移，保证词库与掌握度可写。
2. 前端删除口语主流程，接入收藏。
3. 前端完成词库和一张复习卡。
4. 合并分支，使用两段不同视频跑通。
5. 再制作商业首页的沉浸式视觉和 Demo 录屏。
