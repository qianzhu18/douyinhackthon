# 赛事提交叙事

## 项目标题

**这一帧怎么说**

## 一句话简介（50 字内）

面向抖音内容学习者，暂停视频即可识别画面表达并生成个性化帧词卡，让刷到的世界变成可复习的语言记忆。

## 面向评委的项目介绍骨架

### 1. 真实场景

用户刷短视频时频繁遇到“看得懂画面、却不知道怎么说”的瞬间。传统搜索要求先输入关键词，传统背词又脱离内容；两者都无法承接短视频中即时产生的好奇心。

### 2. 视觉搜索为什么必要

用户可以暂停或圈选对象、动作和场景，不必用文字描述。视觉模型理解画面的主体、关系和状态，生成用户真正想知道的目标语言表达。

### 3. 体验闭环

暂停一帧 → 识别表达 → 按语言水平筛选 → 加入帧词库 → 画面复习 → 下次推荐未掌握表达。

### 4. 抖音生态价值

视觉搜索把 Feed 的暂停行为变成可延展学习入口：用户可能回看同一段视频确认表达，也会在之后回到词库重温原视频语境。项目需要验证“识别触发率、同视频重播率、词库入库率、复习完成率”。

### 5. AI Workflow

```text
视频/图片帧
  → 视觉理解（物品、动作、场景关系）
  → 用户难度与已掌握概念过滤
  → 结构化学习点
  → 词条详情与帧词卡
  → 用户收藏/复习反馈
  → 掌握度更新与下次推荐
```

## 体验流程文案

1. 打开体验页，上传一段本地视频，或进入模拟的 Feed 视频。
2. 在你感兴趣的一帧点击暂停；系统会在约数秒内标出 3–5 个表达。
3. 点击任一标签，查看中文释义、发音、画面例句和常用搭配。
4. 点击“加入帧词库”，把不会的表达保存为带画面语境的词卡。
5. 打开“我的帧词库”，完成一张“认识 / 再看看”的复习卡。

## Demo 视频脚本（约 90 秒）

1. 0–15 秒：刷到一段视频，停在“看见却不会说”的画面。
2. 15–35 秒：暂停并展示 AI 识别、难度标签和位置对应。
3. 35–50 秒：打开一个词的详情并加入帧词库。
4. 50–70 秒：词库显示它来自这段视频；进入复习卡。
5. 70–90 秒：说明下一次识别会跳过已掌握词，短视频成为持续更新的个人语言素材。

## Skill 加分项

封装名：`frame-vocabulary-search`

Skill 的输入为一张视频暂停帧、目标语言、CEFR 难度、已掌握/屏蔽概念；输出为带坐标、词性、目标语言表达、中文释义和规范 concept 的学习点 JSON。后续可被抖音 Feed 长按入口、相机入口或视频上传入口复用。
