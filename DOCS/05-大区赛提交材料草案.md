## 6. 项目标题

**这一帧怎么说**

## 7. 一句话简介（50 字内）

面向短视频学习者，暂停画面即可识别英语表达并沉淀为可复习的帧词卡。

## 8. 项目介绍文档

### 一、我们想解决什么问题

刷旅行、美食、城市生活或海外 Vlog 时，用户常常能看懂画面，却说不出画面中的物品、动作和场景表达。传统搜索要求先把“看见的东西”描述成关键词；传统背词 App 又与当下正在看的内容脱节。好奇心在视频里被触发，却没有形成记忆。

“这一帧怎么说”把短视频中的暂停瞬间变成视觉搜索入口：用户不必先会描述，只要停在感兴趣的一帧，AI 就理解画面并给出适合当前英语水平的表达。

### 二、目标用户与真实场景

目标用户是刷短视频时想顺手学英语、但不愿切换到词表或搜索框的年轻学习者。典型场景包括：看见咖啡师操作设备、旅行 Vlog 的街景、户外活动中的物品或动作，想知道“这一幕英语怎么说”。

在抖音 Feed 中，暂停、回看、截图本来就是自然行为。我们把这一步承接为“长按/暂停 → 搜索这一帧”，降低视觉内容到语言表达之间的转换成本。

### 三、为什么必须用视觉搜索

用户真正想问的往往不是一个已知单词，而是“画面里这个动作/这个物品/这个场景怎么说”。这类需求很难先用文本准确描述；一张暂停帧却同时提供对象、动作、人物关系和环境。

因此，图像/视频不是装饰输入，而是检索意图本身。视觉理解负责从画面中找到可学习的语言点，文本和语音朗读负责帮助用户理解与记忆。

### 四、产品闭环

```text
刷到视频或打开相机
  → 暂停感兴趣的一帧
  → AI 识别物品、动作、场景表达
  → 按 A1–A2 / B1–B2 / C1–C2 筛出 3–5 个学习点
  → 查看释义、发音、画面例句与翻译
  → 收藏为带原画面的帧词卡
  → 在碎片时间完成“认识 / 再看看”复习
  → 下次优先推荐仍未掌握的表达
```

“帧词卡”把词和用户亲眼看过的视频画面绑定：用户背下的不是脱离语境的词表，而是曾经看见过的世界。

### 五、AI Workflow / Agent 流程

```text
输入：视频暂停帧 / 相机帧 + 目标语言 + CEFR 难度 + 已收藏/屏蔽词
  ↓
视觉理解：识别主体、动作、场景关系和可学习表达
  ↓
个性化筛选：结合难度、已掌握概念和黑名单，输出 3–5 个新学习点
  ↓
结构化生成：坐标、词性、表达、中文释义、CEFR 等级
  ↓
词条扩展：发音、符合该帧的自然例句、翻译、常用搭配
  ↓
工具调用：保存私有帧词卡、生成复习队列、更新掌握度
  ↓
满足判断：用户收藏、跳过、认识或再看看，成为下一次推荐依据
```

技术上，完整视频始终留在本机浏览器；仅在用户暂停时将压缩后的当前帧送入视觉模型。收藏后，词条元数据与缩略帧保存到用户私有词库；匿名学习账户在同一浏览器内持续复用，并有本机词库镜像应对网络波动。

### 六、抖音生态价值与增长假设

项目的业务假设是：当视频里的表达被标注出来，用户会更愿意暂停、观察和重播同一段视频，以确认表达与画面的关系；而收藏后的帧词卡会让用户在之后回到原语境复习。

这让视觉搜索不止完成一次“这是什么”，还把 Feed 的兴趣触发延展为个人学习资产。后续可验证的指标包括：视觉搜索触发率、标注点击率、入库率、同视频重播率、复习完成率和掌握推进率。

### 七、创新点与后续延展

1. **从视觉搜索到记忆闭环**：结果不是一次性答案，而是可复习的帧词卡。
2. **同帧不同难度**：同一画面可按用户 CEFR 水平给出“刚好多一步”的表达，而不是一套固定标签。
3. **可落地的隐私边界**：不上传完整视频；只处理用户主动暂停的单帧。
4. **可复用的 Skill**：视觉帧词汇搜索可接入抖音 Feed 长按、相机、图片或视频上传等入口，并扩展到日语、韩语及更多垂类。

## 9. 体验流程（可直接粘贴）

打开体验链接后，可点击“示例画面”立即体验，或上传一段本地视频，也可进入手机相机模式。选择英语难度（A1–A2、B1–B2 或 C1–C2），在想学习的画面点击暂停，等待约 3–8 秒，系统会在画面上标出 3–5 个物品、动作或场景表达。点击任一标签即可查看中文释义、系统朗读、与该画面匹配的英文例句和中文翻译；可点按/长按例句中的词继续查词。点击“加入帧词库”后，表达会连同画面保存；打开“词库”可查看按场景沉淀的卡片，并立即完成一次“认识 / 再看看”复习。建议评委优先使用“示例画面”录制或体验，网络正常时全流程约 1 分钟。

| 时间 | 画面 | 旁白/字幕重点 |
| --- | --- | --- |
| 0–10 秒 | 刷到咖啡馆或旅行视频，停在一帧 | “看得见，却一时说不出——这就是短视频里的语言搜索需求。” |
| 10–25 秒 | 选择 B1–B2，点击暂停，出现识别标签 | “AI 看懂画面中的物品、动作和场景，并按你的水平挑出刚好多一步的表达。” |
| 25–45 秒 | 打开一个词条详情 | “每个表达都有画面例句、翻译和朗读；点例句中的词，还能继续追问。” |
| 45–58 秒 | 加入帧词库 | “把不会的表达连同这一帧收进词库，不让它只停留在一次识别。” |
| 58–78 秒 | 进入词库并立即复习 | “之后在碎片时间，看着原来的画面回答：认识，还是再看看。” |
| 78–90 秒 | 回到主页/闭环图 | “暂停一帧，学会一种说法；让短视频从一次浏览，变成能反复回看的个人语言素材。” |
