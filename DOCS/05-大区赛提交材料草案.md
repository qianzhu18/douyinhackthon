**这一帧怎么说**

## 7. 一句话简介（50 字内）

相机是你眼前的生活，短视频是你想去的生活——指着任何一帧，学会它的英文说法。

## 8. 项目介绍文档

> 项目介绍建议以 [《赛道立项与资源申请方案》](./06-赛道立项与资源申请方案.md) 为主文档；本文件保留用于逐项粘贴提交表单。

### 一、我们想解决什么问题

学了多年英语的人，往往说不出自己的生活。背了几千个词，站在自己家里说不出十样东西的英文；课本教你谈论伦敦的天气，没人教你"花洒""共享充电宝""地铁闸机"怎么说。

而"这个用英语怎么说"的好奇心每天真实发生：路上看到的东西、刷到的想去的地方、别人的日常。词典要求你先会描述，拍照翻译只翻画面上已有的文字、翻完即走，背词 App 的词表和你的生活无关。这个带着画面的好奇心瞬间，没有工具接得住。

"这一帧怎么说"把这个瞬间变成视觉搜索入口：不用描述、不用打字，指着就行——AI 看懂画面，按你的水平给出那个场景里真能用的说法，并连同画面存成你自己的词卡。

### 二、目标用户与真实场景

目标用户是学过英语、却经常在生活中"看见但说不出"的人。两个并列的真实入口：

- **相机 = 我眼前的生活**：厨房里的咖啡机、街边的招牌动作、办公室里的物件——打开相机指着，就知道怎么说。
- **短视频 = 你想去的生活**：刷到想去的城市、向往的别人的日常，暂停一帧，学会"那一幕"的说法，像一次提前的场景预演。

两个入口共用同一套视觉搜索能力：一个覆盖眼前，一个覆盖向往。

### 三、为什么必须用视觉搜索

用户之所以问"这个怎么说"，恰恰因为不会描述——画面本身就是 query。一个暂停帧同时携带对象、动作、人物关系与环境，这是词典和翻译都给不了的上下文。

与拍照翻译的区别：翻译处理画面上*已有的文字*，翻完即走；我们给*没有文字的画面*配语言，并按水平筛选值得学的表达、沉淀为可复习的素材。与背词 App 的区别：词表是它的，而我们的词库从用户自己的生活里长出来——每个词都绑着一帧亲眼见过的画面，这正是记忆最需要的钩子。

### 四、产品闭环

```text
看到眼前的东西，或刷到想去的地方
  → 拍一帧 / 暂停一帧
  → AI 识别物品、动作、场景表达
  → 按 A1–A2 / B1–B2 / C1–C2 筛出 3–5 个学习点
  → 查看释义、发音、画面例句与翻译
  → 收藏为带原画面的帧词卡
  → 在碎片时间完成"认识 / 再看看"复习
  → 下次优先推荐仍未掌握的表达
```

"帧词卡"把词和用户亲眼见过的画面绑定：用户记住的不是脱离语境的词表，而是自己的生活和向往的世界。

### 五、AI Workflow / Agent 流程

```text
输入：相机帧 / 视频暂停帧 + 目标语言 + CEFR 难度 + 已收藏/屏蔽词
  ↓
视觉理解：识别主体、动作、场景关系和可学习表达
  ↓
个性化筛选：结合难度、已掌握概念和黑名单，输出 3–5 个新学习点
  ↓
结构化生成：坐标、词性、表达、中文释义、CEFR 等级
  ↓
词条扩展：发音、符合该帧的自然例句、翻译、常用搭配
  ↓
工具调用：保存私有帧词卡、生成复习队列、更新掌握度
  ↓
满足判断：用户收藏、跳过、认识或再看看，成为下一次推荐依据
```

技术上，完整视频始终留在本机浏览器；仅在用户暂停/拍摄时将压缩后的单帧送入视觉模型。收藏后，词条元数据与缩略帧保存到用户私有词库；匿名学习账户在同一浏览器内持续复用，并有本机词库镜像应对网络波动。

### 六、抖音生态价值与增长假设

产品本身独立成立（相机模式不依赖任何内容平台），抖音的角色是放大器：它有海量别人真实生活的画面——用户没去成的地方、别人的日常，都是"想去的生活"的课本。

业务假设是：当视频里的表达被标注出来，用户会更愿意暂停、观察和重播同一段视频，以确认表达与画面的关系；收藏后的帧词卡会让用户在之后回到原语境复习。后续可验证的指标包括：视觉搜索触发率、标注点击率、入库率、同视频重播率、复习完成率和掌握推进率。

### 七、创新点与后续延展

1. **把世界变成课本**：学习素材不再是统一词表，而是用户眼前的生活和想去的地方——相机与短视频双入口共用一套视觉搜索能力。
2. **同帧不同难度**：同一画面可按用户 CEFR 水平给出"刚好多一步"的表达，而不是一套固定标签。
3. **从识别到记忆闭环**：结果不是一次性答案，而是带着原画面、可复习的帧词卡。
4. **可落地的隐私边界**：不上传完整视频；只处理用户主动拍摄/暂停的单帧。
5. **可复用的 Skill**：视觉帧词汇搜索可接入相机、Feed 暂停、图片或视频上传等入口，并扩展到日语、韩语及更多垂类。

## 9. 体验流程（可直接粘贴）

打开体验链接后，有三种视觉入口：点击"示例画面"立即体验（推荐评委优先使用，演示最稳定）；上传一段本地视频；或进入手机相机模式，直接对着现场物品识别"眼前的生活"。选择英语难度（A1–A2、B1–B2 或 C1–C2），在想学习的画面点击暂停（相机模式直接取景），等待约 3–8 秒，系统会在画面上标出 3–5 个物品、动作或场景表达。点击任一标签即可查看中文释义、系统朗读、与该画面匹配的英文例句和中文翻译；可点按/长按例句中的词继续查词。点击"加入帧词库"后，表达会连同画面保存；打开"词库"可查看按场景沉淀的卡片，并立即完成一次"认识 / 再看看"复习。网络正常时全流程约 1 分钟。

## 13. Skill 封装文件（加分项）

已生成可直接上传的 [frame-vocabulary-search.skill.zip](../deliverables/frame-vocabulary-search.skill.zip)。

Skill 名称：`frame-vocabulary-search`。它将"视觉帧 → 语言意图 → CEFR 分层表达 → 帧词卡 → 收藏/复习/追问反馈"定义为一套可复用的业务协议，而不是单次图像识别提示词：

- 输入：相机帧/暂停帧、来源入口、目标语言、CEFR、圈选区域、已收藏/已掌握/屏蔽概念和用户反馈。
- 决策：优先识别用户真正想知道的动作、关系和场景表达；按难度选择"刚好多一步"的学习点；剔除已掌握和屏蔽内容。
- 输出：含坐标、释义、例句、搭配、唯一 concept 和下一步 action 的结构化结果，可直接接入相机、Feed Tag、帧词库、复习与实验埋点。
- 闭环：用户的收藏、认识、再看看和屏蔽会改变后续推荐，使视觉搜索从一次满足进化为个性化学习循环。

压缩包内容：

```text

└── frame-vocabulary-search/
    ├── SKILL.md
    └── agents/openai.yaml
```
