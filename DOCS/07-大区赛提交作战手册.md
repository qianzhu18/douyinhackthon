## 2. 评审五维对位（评委怎么问 → 我们怎么答）

评审总锚点："是否围绕一个真实场景，把从用户触发到体验展开的过程讲清楚，并让人理解技术在其中是如何自然发挥作用的？"

### 2.1 真实场景成立（20%）

**评委在查**：场景是否真实、触发是否自然，是不是"为了用视觉能力而构造场景"。

**我们的回答**：

- 痛点真实："这个用英语怎么说"是每个人都问过的话——出国对菜单、看剧听台词、给娃指认东西、刷到想去的地方。它不需要学习动机支撑，是带着画面的好奇心瞬间。
- 触发动作原生："指着"和"暂停"都不是新习惯——人对着想问的东西指，是身体本能；暂停/截图已经是 Feed 消费的原生行为。
- 现有工具全都接不住这个瞬间：词典要先会描述（会描述就不会问）；拍照翻译只翻已有文字、翻完即走；背词 App 的词表和生活无关。
- 反"构造场景"的证词：我们的两个典型一幕（厨房咖啡机 / 京都 Vlog 柜台）写进了 06 第 2 节，具体到人和时刻，不是"年轻学习者"画像。

**证据位置**：06 第 1、2 节；演示视频 0–10 秒开场。

### 2.2 多模态必要性（20%）

**评委在查**：为什么必须用图/视频，纯文搜行不行。

**我们的回答**：

- 用户之所以问"这个怎么说"，恰恰因为**不会描述**——文字输入在这个需求上天然失效，画面本身就是 query。
- 一帧画面同时携带对象、动作、人物关系、环境与情绪。它决定 `steam the milk` 和 `counter service` 哪个才是用户此刻想问的——这是文搜给不了的消歧上下文。
- 赛道判词里"我看到的这个是什么""这个怎么用"正是我们的核心场景原话。

**证据位置**：06 第 3 节；同帧不同难度截图。

### 2.3 抖音生态放大（20%）⚠️ 需要特别注意措辞

**评委在查**：判词原文是"**而不是做一个脱离内容生态的独立工具**"。

**我们的措辞策略**：对外表述不说"产品是独立的、抖音只是入口之一"，而说——

- **"想去的生活"的内容供给 100% 来自抖音**：用户没去成的地方、别人的日常，这些画面只有抖音有这样的规模、新鲜度和垂类丰富度（旅行/美食/生活方式/海外日常）。相机覆盖眼前，Feed 覆盖向往，缺了抖音这一半故事不成立。
- 与赛道官方示例（Feed 暂停 tag 搜同款）同构：我们是同一入口形态，只是把"搜同款买下来"延展成"搜这一幕学会它"——语言学习是 Feed 暂停需求里尚未被承接的一类。
- 反哺链路：帧词卡回链原视频时点 → 复习即重播 → 收藏后同视频重播率、回链播放率是我们的内容价值指标（06 第 7 节）。记忆反哺内容消费，这是双向放大，不是单向引流。
- 运营放大：达人共创"这一幕怎么说"专题、旅行目的地话题、节假日/热点（出境游季、留学季）结合，与判词里"运营放大能力"对位。

**证据位置**：06 第 6 节（对外讲时把第 6 节标题口径念成"抖音是放大器"而不是"产品独立成立"）。

### 2.4 AI 链路可落地（25%，权重最高）

**评委在查**：五环是否齐全——需求理解、视觉理解、工具调用、结果生成、满足判断。

**我们的回答（逐环对位）**：

| 评委的五环 | 我们的实现 | 证据 |
| --- | --- | --- |
| 需求理解 | 指向/暂停行为 + CEFR + 已收藏/已掌握/屏蔽概念 → 判断"这是什么 / 怎么说 / 怎么用" | SKILL.md Workflow 1 |
| 视觉理解 | 多模态模型识别主体、动作、关系、场景，输出带坐标的 3–5 学习点 | `/api/analyze` |
| 工具调用 | 帧词库写入、复习队列更新、句中查词（`/api/lookup`）、语音朗读 | 词条抽屉 |
| 结果生成 | 结构化 JSON：释义、发音、画面例句、翻译、搭配，CEFR 分层 | SKILL.md Output contract |
| 满足判断 | 收藏/跳过/认识/再看看/屏蔽 → 更新掌握度与下次推荐；识别失败给可学习降级卡而非裸错误 | SKILL.md 闭环表 |

- 五环不是 PPT：全部在已部署 MVP 上可点。
- Skill 已按赛道要求打包上传（含 SKILL.md），把上述五环定义成可复用协议——直接命中"补充必要 Skill"的判词。

**证据位置**：06 第 5 节 mermaid 图；skill zip；现场演示。

### 2.5 增长与 ROI（15%）

**评委在查**：冷启动怎么做、指标是否清晰、能否放量。

**我们的回答**：

- 冷启动：旅行/美食/生活方式三高视觉密度垂类先行，建表达模板与示例帧；心智是"这一幕怎么说"，不是"背单词"。
- 放量：收藏用户相似内容入口加权 + 复习提醒二次回流 + 达人共创玩法 + 多语言/多垂类延展（动植物、影视、游戏，对应判词里的扩展空间）。
- 指标：入口（触发率）→ 理解（标签点击/追问率）→ 沉淀（入库率）→ 留存（D1/D7 复习回访）→ 内容价值（同视频重播、回链播放），配 H1–H3 A/B 假设，因果可验证（06 第 7 节）。
- 诚实口径：全部表述为"待验证假设"，不包装成已取得的线上结论——这反而是加分项，评委反感编造数据。

**证据位置**：06 第 6、7 节。
