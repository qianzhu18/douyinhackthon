## 当前决策

- 产品是**视觉词汇搜索与记忆产品**，不是口语评分产品。
- 视频是触发器；用户暂停的一帧是搜索词；帧词卡是可沉淀的结果。
- 语音可作为未来的追问输入，但不在本次 MVP 主路径内。
- 当前前后端只做一条闭环：`暂停 → 识别 → 收藏 → 复习 → 下次更懂你`。
