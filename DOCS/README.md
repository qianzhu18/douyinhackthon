## 当前决策

- 核心命题：**学了多年英语的人，说不出自己的生活。** 产品承接"这个用英语怎么说"的好奇心瞬间，而不是"我要学英语"的学习动机。
- 两个并列入口：**相机 = 我眼前的生活，短视频 = 你想去的生活。** 两者共用同一套视觉语言搜索能力。
- 与拍照翻译的差异：翻译处理画面上已有的文字、翻完即走；我们给没有文字的画面配语言，并沉淀为可复习的帧词卡。
- 抖音是放大器而非全部：产品独立成立，Feed 提供"别人的生活"这一最大内容供给。
- 语音可作为未来的追问输入，但不在本次 MVP 主路径内。
- 当前前后端只做一条闭环：`指着/暂停 → 识别 → 收藏 → 复习 → 下次更懂你`。
